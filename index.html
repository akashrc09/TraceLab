    About & limitations

    TraceLab runs without a backend or remote library. File contents are read by this page only; case records, if saved, use the browser’s local storage and may persist on this device. Clear case data on shared devices. No evidence is uploaded automatically.

    • Secure context: Web Crypto SHA algorithms require HTTPS or localhost in browsers. MD5 uses an in-page implementation and is for legacy comparison only.
    • Hash size limit: files larger than 128 MiB are rejected to avoid unbounded memory use. Hashing is not incremental and can temporarily use additional memory.
    • Metadata: standard browser file properties and basic signatures are available. This build does not parse EXIF, full document metadata, PDF page trees, or embedded content.
    • PCAP: only classic PCAP, Ethernet, IPv4, TCP/UDP basic records. PCAPNG and other link/network formats are unsupported. Parser output is not a complete protocol analysis.
    • Logs/timeline: simple transparent timestamp and keyword heuristics; formats vary. Original text remains visible. UTC conversion is only made for timestamps with explicit timezone or recognized epoch values.
    • Not a forensic acquisition tool: no write blocking, deleted data recovery, verified chain-of-custody, tamper-proof audit, malware verdict, or court-readiness. Validate important results with established tools and controlled procedures.

    No third-party libraries are used. Static HTML/CSS/JavaScript is suitable for local use and GitHub Pages.
